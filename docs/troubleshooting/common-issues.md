# 常见问题

本页面汇总了使用 FlowUs Limbic 时常见的问题及解决方案。

## 安装问题

### Q: 插件不显示在 Obsidian 插件列表中？

**可能原因**:
- 文件放置位置不正确
- 插件文件夹名称不对
- Obsidian 版本不兼容

**解决方案**:
1. 确认 `main.js` 和 `manifest.json` 已正确放置在以下位置：
   - **Windows**: `%APPDATA%\Obsidian\plugins\flowus-limbic\`
   - **macOS**: `~/Library/Application Support/Obsidian/plugins/flowus-limbic/`
   - **Linux**: `~/.config/obsidian/plugins/flowus-limbic/`
2. 确认文件夹名称为 `flowus-limbic`（全小写，带连字符）
3. 检查 Obsidian 版本是否满足 `manifest.json` 中的 `minAppVersion` 要求
4. 重启 Obsidian

### Q: 插件无法启用？

**可能原因**:
- `main.js` 文件损坏或缺失
- 插件依赖的 Obsidian API 版本不匹配
- 其他插件冲突

**解决方案**:
1. 重新下载或重新构建插件
2. 检查 Obsidian 控制台（`Ctrl/Cmd + Shift + I`）中的错误信息
3. 尝试禁用其他插件，逐个排查冲突
4. 更新 Obsidian 到最新版本

## 授权问题

### Q: 点击授权按钮没有反应？

**可能原因**:
- Client ID 或 Client Secret 未填写
- 浏览器拦截了弹出窗口
- 网络连接问题

**解决方案**:
1. 确认在插件设置中已正确填写 Client ID 和 Client Secret
2. 检查浏览器是否阻止了弹出窗口，允许来自 Obsidian 的弹出窗口
3. 检查网络连接是否正常
4. 尝试手动复制授权 URL 到浏览器打开

### Q: 授权后显示"重定向 URI 不匹配"？

**可能原因**:
- FlowUs 应用中配置的重定向 URI 不正确
- 重定向 URI 有多余的空格或字符

**解决方案**:
1. 登录 [FlowUs 开发者中心](https://api.flowus.cn/)
2. 检查您的应用设置中的重定向 URI
3. 确认重定向 URI 完全为 `obsidian://flowus-limbic-callback`
4. 注意大小写敏感，不能有末尾斜杠或查询参数

### Q: 授权成功但很快就过期了？

**可能原因**:
- 刷新令牌配置有问题
- 令牌没有正确保存

**解决方案**:
1. 检查 FlowUs 应用设置中的刷新令牌有效期
2. 在插件设置中点击"注销"，然后重新授权
3. 检查 Obsidian 是否有足够的权限写入插件数据
4. 查看控制台日志中的错误信息

## 同步问题

### Q: TODO 不同步？

**可能原因**:
- 未完成授权
- Database ID 或 Table Name 配置错误
- 网络连接问题
- FlowUs API 服务异常

**解决方案**:
1. 确认插件设置中显示"已授权"状态
2. 验证 Database ID 和 Table Name 是否正确
3. 检查网络连接，尝试访问 FlowUs 网站
4. 点击"立即同步"按钮，查看是否有错误提示
5. 查看 Obsidian 控制台中的错误信息

### Q: 同步失败，提示"访问令牌已过期"？

**可能原因**:
- 访问令牌确实过期了
- 刷新令牌也过期了
- 令牌刷新失败

**解决方案**:
1. 在插件设置中点击"注销"
2. 重新进行授权流程
3. 如果问题持续，检查 FlowUs 应用中的令牌有效期设置

### Q: 同步失败，提示"数据库不存在"？

**可能原因**:
- Database ID 错误
- 数据库已被删除
- 应用没有访问该数据库的权限

**解决方案**:
1. 确认 Database ID 正确（从 FlowUs 数据库 URL 中复制）
2. 确认数据库仍然存在且您有访问权限
3. 在 FlowUs 中打开数据库，检查是否可以正常访问
4. 确认您的 FlowUs 应用有数据库读取权限

### Q: 部分 TODO 同步成功，部分失败？

**可能原因**:
- 某些 TODO 的数据格式不符合要求
- FlowUs 数据库字段不匹配
- 单个 TODO 数据过大

**解决方案**:
1. 查看控制台日志，找出失败的 TODO
2. 检查失败 TODO 的内容是否包含特殊字符
3. 确认 FlowUs 数据库包含所有必需的字段
4. 尝试在 FlowUs 中手动创建类似的 TODO，看是否成功

## 数据问题

### Q: FlowUs 中的 TODO 没有出现在 Obsidian 中？

**可能原因**:
- 同步方向设置为"仅推送"
- TODO 的创建时间早于插件的同步起始时间
- 数据筛选条件隐藏了 TODO

**解决方案**:
1. 检查插件设置中的同步方向，确保是"双向同步"或"仅拉取"
2. 在 TODO 视图中调整筛选条件，尝试选择"全部"
3. 点击"立即同步"按钮，等待同步完成
4. 查看同步日志，确认拉取了多少条记录

### Q: 在 Obsidian 中删除的 TODO 又出现了？

**可能原因**:
- 同步方向设置为"仅拉取"
- 冲突解决策略设置为"远程优先"
- 删除操作没有成功同步

**解决方案**:
1. 检查同步方向设置
2. 检查冲突解决策略设置
3. 在 FlowUs 中手动删除该 TODO
4. 查看同步日志，确认删除操作是否成功

### Q: 数据重复？

**可能原因**:
- 多次同步时 ID 匹配失败
- 离线编辑后同步产生冲突
- 网络中断导致部分同步

**解决方案**:
1. 识别重复的 TODO，删除多余的副本
2. 在插件设置中点击"重置缓存"
3. 重新进行完整同步
4. 如果问题持续，导出数据后清理再导入

## 性能问题

### Q: 插件导致 Obsidian 变慢？

**可能原因**:
- 同步间隔设置太短
- TODO 数量过多
- 每次同步都进行全量同步

**解决方案**:
1. 调长同步间隔（建议 1-2 分钟）
2. 清理已完成的旧 TODO
3. 在 TODO 视图中启用"隐藏已完成"
4. 检查是否有其他插件也在占用资源

### Q: 同步速度很慢？

**可能原因**:
- 网络连接慢
- TODO 数量很多
- 批量大小设置过小

**解决方案**:
1. 检查网络连接速度
2. 在高级设置中调大"批量大小"
3. 减少同时同步的数据量
4. 避开网络高峰期

## 界面问题

### Q: TODO 视图不显示？

**可能原因**:
- 视图面板被关闭
- 侧边栏被隐藏
- CSS 样式冲突

**解决方案**:
1. 通过命令面板（`Ctrl/Cmd + P`）执行 "FlowUs TODO: Open View"
2. 检查 Obsidian 侧边栏是否已展开
3. 尝试禁用其他可能冲突的插件
4. 查看控制台是否有 CSS 相关错误

### Q: TODO 列表显示乱码或格式错误？

**可能原因**:
- 特殊字符没有正确处理
- Markdown 渲染问题
- 编码问题

**解决方案**:
1. 检查 TODO 内容是否包含特殊字符
2. 尝试编辑并重新保存该 TODO
3. 查看原始数据是否正常

## 其他问题

### Q: 如何重置插件？

**解决方案**:
1. 在插件设置中点击"重置缓存"（仅清除缓存，保留数据）
2. 或完全重置：
   - 关闭 Obsidian
   - 删除插件文件夹中的 `data.json` 文件
   - 重新打开 Obsidian
   - 重新配置插件

### Q: 如何导出我的数据？

**解决方案**:
1. 在插件设置中找到"导出数据"按钮
2. 点击并选择导出格式（JSON/CSV）
3. 保存文件到本地
4. 或直接在 FlowUs 中导出数据库

### Q: 如何提交 Bug 报告？

**解决方案**:
1. 打开 Obsidian 控制台（`Ctrl/Cmd + Shift + I`）
2. 复现问题
3. 截图或复制控制台中的错误信息
4. 访问 [GitHub Issues](https://github.com/yourusername/FlowUs-Limbic/issues)
5. 创建新 Issue，包含：
   - 问题描述
   - 复现步骤
   - 错误信息
   - 您的环境信息（Obsidian 版本、插件版本、操作系统）

### Q: 还有其他问题？

如果以上解决方案都不能解决您的问题：

1. 查看 [调试技巧](./debugging.md) 了解如何获取更多信息
2. 检查 [GitHub Issues](https://github.com/yourusername/FlowUs-Limbic/issues) 是否有类似问题
3. 提交新的 Issue，我们会尽快回复
