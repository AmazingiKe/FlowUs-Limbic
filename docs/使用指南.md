# FlowUs Limbic 使用指南

## 概述

FlowUs Limbic 是一个 Obsidian 插件，实现了 Obsidian 与 FlowUs 数据库的双向实时同步，特别针对 TODO 功能进行了优化。本指南将详细介绍如何安装、配置和使用此插件。

## 安装步骤

### 1. 下载插件

1. 访问 [FlowUs Limbic GitHub 仓库](https://github.com/yourusername/FlowUs-Limbic)
2. 点击 "Code" 按钮，选择 "Download ZIP" 下载最新版本
3. 解压 ZIP 文件到本地目录

### 2. 构建插件

1. 打开命令行工具，进入插件目录：
   ```bash
   cd FlowUs-Limbic
   ```

2. 安装依赖：
   ```bash
   npm install
   ```

3. 构建插件：
   ```bash
   npm run build
   ```

### 3. 安装到 Obsidian

1. 找到 Obsidian 插件目录：
   - Windows: `%APPDATA%\Obsidian\plugins\`
   - macOS: `~/Library/Application Support/Obsidian/plugins/`
   - Linux: `~/.config/obsidian/plugins/`

2. 在插件目录中创建 `flowus-limbic` 文件夹

3. 将以下文件复制到 `flowus-limbic` 文件夹：
   - `main.js`
   - `manifest.json`

4. 启用插件：
   - 打开 Obsidian
   - 进入 `设置` → `社区插件`
   - 找到 `FlowUs Limbic` 并启用

## 配置步骤

### 1. 获取 FlowUs 应用凭证

1. 访问 [FlowUs 开发者平台](https://api.flowus.cn/)
2. 登录您的 FlowUs 账户
3. 点击"创建应用"按钮
4. 填写应用信息：
   - 应用名称：FlowUs Limbic
   - 应用描述：Obsidian 与 FlowUs 数据库同步工具
   - 重定向 URI：`obsidian://flowus-limbic-callback`
5. 创建成功后，记录以下信息：
   - **Client ID**：应用标识符
   - **Client Secret**：应用密钥（请妥善保管）

### 2. 配置 FlowUs 数据库

1. 在 FlowUs 中创建一个新的数据库
2. 确保数据库包含以下字段：
   - `title`（标题）：文本类型
   - `completed`（完成状态）：复选框类型
3. 可选字段：
   - `description`（描述）：文本类型
   - `priority`（优先级）：选择类型（高/中/低）
   - `dueDate`（截止日期）：日期类型
4. 记录数据库的 ID 和表名：
   - 数据库 ID 可在数据库 URL 中找到
   - 表名通常是数据库的名称

### 3. 在 Obsidian 中配置插件

1. 打开 Obsidian 设置
2. 找到 `FlowUs Limbic` 插件设置
3. 填写以下信息：
   - **Client ID**：从 FlowUs 开发者平台获取
   - **Client Secret**：从 FlowUs 开发者平台获取
   - **Database ID**：FlowUs 数据库的 ID
   - **Table Name**：数据库表名

### 4. 完成授权

1. 在插件设置中点击"授权"按钮
2. 浏览器将自动打开并跳转到 FlowUs 授权页面
3. 登录并授权应用访问您的 FlowUs 数据
4. 授权完成后，插件将自动保存访问令牌

## 使用方法

### 创建 TODO

1. 在 Obsidian 中打开 FlowUs TODO 视图：
   - 通过命令面板（Ctrl/Cmd + P）搜索"FlowUs TODO"
   - 或在侧边栏中找到 FlowUs 图标

2. 在输入框中输入 TODO 内容
3. 点击"添加"按钮或按 Enter 键
4. TODO 将自动同步到 FlowUs 数据库

### 管理 TODO

- **标记完成**：点击 TODO 项前的复选框
- **编辑 TODO**：点击 TODO 项的文本内容进行编辑
- **删除 TODO**：点击 TODO 项右侧的"删除"按钮
- **查看状态**：已完成的 TODO 会显示删除线

### 高级功能

#### 1. 设置优先级

1. 创建或编辑 TODO 时，可以设置优先级：
   - 高：标记为红色
   - 中：标记为黄色
   - 低：标记为绿色

2. 优先级信息会同步到 FlowUs 数据库

#### 2. 设置截止日期

1. 创建或编辑 TODO 时，可以设置截止日期
2. 接近截止日期的 TODO 会高亮显示
3. 过期的 TODO 会以红色标记

#### 3. 添加描述

1. 点击 TODO 项展开详细视图
2. 在描述字段中添加详细信息
3. 支持 Markdown 格式

### 自动同步

- 插件默认每 30 秒自动同步一次
- 可以在插件设置中调整同步间隔：
  - 最短间隔：10 秒
  - 最长间隔：5 分钟
- 手动触发同步：在插件设置中点击"立即同步"按钮

### 离线使用

1. 插件支持离线模式，可以在没有网络连接时继续使用
2. 所有更改会在本地缓存
3. 网络恢复后自动同步所有更改

## 故障排除

### 授权失败

**问题**：点击"授权"按钮后无法完成授权流程

**解决方案**：
1. 检查 Client ID 和 Client Secret 是否正确
2. 确认重定向 URI 是否设置为 `obsidian://flowus-limbic-callback`
3. 检查网络连接是否正常
4. 尝试清除浏览器缓存后重新授权

### 同步失败

**问题**：TODO 项目无法同步到 FlowUs 数据库

**解决方案**：
1. 检查访问令牌是否已过期，尝试重新授权
2. 确认 Database ID 和 Table Name 配置是否正确
3. 检查 FlowUs 数据库是否包含必需的字段（title, completed）
4. 查看 Obsidian 控制台（Ctrl+Shift+I）获取详细错误信息

### 插件无法加载

**问题**：在 Obsidian 中无法找到或启用 FlowUs Limbic 插件

**解决方案**：
1. 确认 `main.js` 和 `manifest.json` 已正确放置在插件目录
2. 检查 Obsidian 版本是否满足 `minAppVersion` 要求
3. 查看 Obsidian 控制台是否有错误信息
4. 尝试重新启动 Obsidian

### 性能问题

**问题**：插件导致 Obsidian 运行缓慢

**解决方案**：
1. 调整同步间隔，减少同步频率
2. 减少同时同步的 TODO 数量
3. 清除本地缓存：在插件设置中点击"重置缓存"按钮

## 最佳实践

### 1. 数据库设计

- 为不同类型的 TODO 创建不同的数据库
- 使用标签或分类字段组织 TODO
- 定期清理已完成的 TODO

### 2. 命名规范

- 使用清晰、简洁的 TODO 标题
- 在描述中提供必要的上下文信息
- 使用一致的优先级标记

### 3. 工作流程

- 定期审查和更新 TODO 列表
- 使用截止日期管理时间敏感的任务
- 利用优先级专注于重要任务

## 高级配置

### 1. 自定义同步规则

可以通过编辑插件配置文件来自定义同步规则：

```json
{
  "syncRules": {
    "syncCompleted": true,
    "syncDeleted": false,
    "syncInterval": 30,
    "conflictResolution": "local"
  }
}
```

### 2. 集成其他插件

FlowUs Limbic 可以与其他 Obsidian 插件集成：

- **Calendar 插件**：将截止日期同步到日历视图
- **Kanban 插件**：将 TODO 显示在看板中
- **Templates 插件**：使用模板快速创建标准化的 TODO
