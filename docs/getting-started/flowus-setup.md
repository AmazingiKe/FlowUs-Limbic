# FlowUs 配置指南

本指南将帮助您快速配置 FlowUs 开发者账户，以便与 FlowUs Limbic 插件配合使用。

## 步骤 1：访问 FlowUs 开发者中心

1. 打开浏览器，访问 [FlowUs 开发者中心](https://api.flowus.cn/)
2. 使用您的 FlowUs 账户登录
3. 如果是首次访问，可能需要完成开发者注册

## 步骤 2：创建应用

1. 登录后，点击"创建应用"或"新建应用"按钮
2. 填写应用基本信息：

   | 字段 | 值 |
   |------|-----|
   | **应用名称** | FlowUs Limbic |
   | **应用描述** | Obsidian 与 FlowUs 数据库同步工具，实现双向实时同步 |
   | **应用类型** | Web 应用 或 桌面应用 |

3. （可选）上传应用图标

## 步骤 3：配置 OAuth 设置

在应用设置中，找到"OAuth 配置"部分，配置以下参数：

| 参数 | 值 |
|------|-----|
| **授权模式** | Authorization Code |
| **授权范围** | all（或根据需要选择特定权限） |
| **重定向 URI** | `obsidian://flowus-limbic-callback` |
| **访问令牌有效期** | 建议 1 小时 |
| **刷新令牌有效期** | 建议 30 天 |

> **重要**：重定向 URI 必须完全匹配 `obsidian://flowus-limbic-callback`，包括协议和路径，不能有多余的斜杠或参数。

## 步骤 4：安全设置（推荐）

在"安全设置"部分：

- ✅ 启用"PKCE"（推荐）
- ✅ 设置"状态参数"验证
- （可选）配置"IP 白名单"

## 步骤 5：获取应用凭证

创建应用后，您将获得以下凭证：

- **Client ID**: 应用标识符
- **Client Secret**: 应用密钥（请妥善保管！）
- **应用 ID**: 应用在 FlowUs 系统中的唯一标识

> **安全提示**：
> - Client Secret 是敏感信息，请勿分享或提交到公开仓库
> - 不要在客户端代码中暴露 Client Secret
> - 定期轮换 Client Secret 以提高安全性

## 步骤 6：配置 API 权限

FlowUs Limbic 插件需要以下 API 权限：

1. **数据库读取权限**: 读取 FlowUs 数据库内容
2. **数据库写入权限**: 创建、更新、删除数据库记录
3. **用户信息权限**: 获取基本用户信息

在开发者中心的"权限管理"部分，确保为您的应用授予这些权限。

## 步骤 7：创建数据库

1. 登录 FlowUs 主应用
2. 创建一个新的数据库用于 TODO 管理
3. 设置数据库结构，确保包含以下字段：

   | 字段名 | 类型 | 必填 | 说明 |
   |--------|------|------|------|
   | `title` | 文本 | ✅ | TODO 标题 |
   | `completed` | 复选框 | ✅ | 完成状态 |
   | `description` | 文本 | ❌ | 详细描述 |
   | `priority` | 选择 | ❌ | 优先级（高/中/低） |
   | `dueDate` | 日期 | ❌ | 截止日期 |

## 步骤 8：获取数据库信息

1. 打开刚创建的数据库
2. 在浏览器地址栏中找到数据库 ID
   - URL 格式通常为：`https://flowus.cn/database/[数据库ID]`
3. 记录数据库 ID 和表名

## 测试应用（可选）

FlowUs 开发者中心提供了测试工具：

1. 在应用详情页找到"测试工具"部分
2. 输入重定向 URI：`obsidian://flowus-limbic-callback`
3. 点击"测试授权"按钮
4. 验证授权流程是否正常工作
