# 项目概述

## 什么是 FlowUs Limbic？

FlowUs Limbic 是一个 Obsidian 插件，实现了 Obsidian 与 FlowUs 数据库之间的**双向实时同步**，特别针对 TODO 任务管理功能进行了优化。

## 核心功能

### 🔄 双向同步
- 本地变更自动同步到 FlowUs
- FlowUs 变更自动拉取到本地
- 基于时间戳的增量同步，最小化 API 调用
- 冲突检测与自动解决

### ✅ TODO 管理
- 在 Obsidian 中直接创建、编辑、删除 TODO
- 支持标记完成、设置优先级
- 截止日期提醒
- 富文本描述支持

### 🔐 安全认证
- OAuth 2.0 协议，安全访问 FlowUs API
- 自动令牌刷新，无需重复授权
- 令牌加密存储

### ⚡ 高性能
- 可配置的同步间隔（10秒 - 5分钟）
- 批量操作支持
- 离线模式，网络恢复后自动同步

## 适用场景

- **个人任务管理**：在 Obsidian 中记笔记的同时管理 TODO，同步到 FlowUs 进行跨设备访问
- **团队协作**：团队成员在 FlowUs 中协作管理任务，个人在 Obsidian 中查看和更新
- **数据备份**：将 Obsidian 中的重要数据同步到 FlowUs 进行备份
- **跨平台访问**：通过 FlowUs 在手机、平板等设备上访问 Obsidian 中的 TODO

## 技术亮点

- **Schema 驱动**：通过声明式 Schema 定义数据模型，轻松扩展新数据类型
- **分层架构**：通用同步层与具体平台解耦，便于支持更多平台
- **依赖注入**：使用 DI 容器管理组件，提高可测试性
- **TypeScript**：完整的类型安全保障

## 与其他同步方案的对比

| 特性 | FlowUs Limbic | 其他同步方案 |
|------|---------------|-------------|
| 实时性 | 支持自动同步（可配置间隔） | 通常需要手动触发 |
| 双向性 | 完整双向同步 | 大多为单向同步 |
| 针对性 | 专为 TODO 优化 | 通用文件同步 |
| 集成度 | 深度集成 Obsidian UI | 独立工具 |
