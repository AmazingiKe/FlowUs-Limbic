# TODO 管理

FlowUs Limbic 提供了完整的 TODO 管理功能，让您可以在 Obsidian 中方便地管理任务，同时自动同步到 FlowUs。

## 打开 TODO 视图

### 通过命令面板

1. 按 `Ctrl/Cmd + P` 打开命令面板
2. 输入 "FlowUs TODO: Open View"
3. 按 Enter 执行

### 通过侧边栏

1. 在 Obsidian 左侧边栏找到 FlowUs 图标
2. 点击图标打开 TODO 视图

## 创建 TODO

### 基本创建

1. 在 TODO 视图顶部的输入框中输入 TODO 内容
2. 按 `Enter` 键或点击"添加"按钮
3. TODO 将自动同步到 FlowUs 数据库

### 创建带优先级的 TODO

1. 在输入框中输入 TODO 内容
2. 点击输入框旁边的优先级按钮
3. 选择优先级（高/中/低）
4. 按 `Enter` 键创建

### 创建带截止日期的 TODO

1. 点击 TODO 视图中的"高级"按钮
2. 在展开的表单中填写：
   - 标题
   - （可选）描述
   - （可选）优先级
   - （可选）截止日期
3. 点击"创建"按钮

## 管理 TODO

### 标记完成

- 点击 TODO 项前的复选框即可标记为完成
- 已完成的 TODO 会显示删除线并变灰
- 再次点击复选框可以取消完成状态

### 编辑 TODO

1. 双击 TODO 项的文本内容
2. 进入编辑模式
3. 修改内容后按 `Enter` 保存
4. 或按 `Esc` 取消编辑

### 查看详情

1. 点击 TODO 项右侧的"详情"按钮（或双击 TODO 项）
2. 在弹出的详情面板中查看和编辑：
   - 标题
   - 描述（支持 Markdown）
   - 优先级
   - 截止日期
   - 创建时间
   - 更新时间

### 删除 TODO

1.  hover 到 TODO 项上
2. 点击右侧的"删除"按钮
3. 确认删除操作

> **注意**: 删除操作会同时删除 FlowUs 中的对应记录，且无法恢复。

## 组织 TODO

### 按状态筛选

在 TODO 视图顶部，您可以选择筛选条件：

- **全部**: 显示所有 TODO
- **未完成**: 只显示未完成的 TODO
- **已完成**: 只显示已完成的 TODO

### 按优先级筛选

- 点击优先级筛选按钮
- 选择要显示的优先级（高/中/低）
- 可多选

### 排序

点击排序按钮可以选择排序方式：

- **按截止日期**: 截止日期近的排在前面
- **按优先级**: 高优先级排在前面
- **按创建时间**: 新创建的排在前面
- **按更新时间**: 最近更新的排在前面

### 搜索

1. 在搜索框中输入关键词
2. TODO 列表会实时过滤显示匹配的项
3. 搜索匹配标题和描述内容

## 批量操作

### 批量标记完成

1. 点击 TODO 视图中的"选择模式"按钮
2. 勾选要标记的 TODO 项
3. 点击"标记完成"按钮

### 批量删除

1. 进入选择模式
2. 勾选要删除的 TODO 项
3. 点击"删除"按钮
4. 确认批量删除

## 键盘快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl/Cmd + P` → "FlowUs TODO: Open View" | 打开 TODO 视图 |
| `Esc` | 关闭详情面板 / 退出编辑 |
| `Enter` (在输入框) | 创建新 TODO |
| `Ctrl/Cmd + Enter` (在详情面板) | 保存更改 |
