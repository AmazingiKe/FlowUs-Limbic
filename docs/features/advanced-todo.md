# 高级 TODO 功能

除了基本的 TODO 管理功能外，FlowUs Limbic 还提供了丰富的高级功能，帮助您更高效地管理任务。

## 优先级管理

### 设置优先级

每个 TODO 都可以设置优先级：

- **高优先级**: 红色标记，显示在列表顶部
- **中优先级**: 黄色标记
- **低优先级**: 绿色标记，显示在列表底部

### 如何设置优先级

1. 创建 TODO 时，点击优先级按钮选择
2. 或在编辑 TODO 时，在详情面板中设置
3. 也可以通过右键菜单快速设置

### 优先级筛选

在 TODO 视图中，您可以按优先级筛选：

- 点击优先级筛选按钮
- 选择要查看的优先级（可多选）
- 例如：只显示高优先级的 TODO

## 截止日期

### 设置截止日期

1. 打开 TODO 详情面板
2. 点击截止日期字段
3. 选择日期和时间（可选）
4. 保存更改

### 截止日期提醒

插件会根据截止日期自动高亮 TODO：

| 状态 | 说明 | 显示样式 |
|------|------|---------|
| **即将到期** | 截止日期在 24 小时内 | 橙色边框 |
| **已过期** | 已超过截止日期 | 红色背景 |
| **今天到期** | 截止日期是今天 | 黄色标记 |

### 按截止日期排序

选择"按截止日期"排序方式：
- 截止日期最近的排在前面
- 没有截止日期的排在最后
- 已完成的 TODO 排在最后

## 标签系统

### 添加标签

1. 打开 TODO 详情面板
2. 在标签字段中输入标签名
3. 按 `Enter` 添加标签
4. 可以添加多个标签

### 标签功能

- **标签筛选**: 点击标签可以只显示带该标签的 TODO
- **标签颜色**: 每个标签自动分配不同颜色
- **标签管理**: 在设置中可以管理常用标签

### 标签示例

常用标签示例：
- `工作` - 工作相关任务
- `个人` - 个人事务
- `学习` - 学习任务
- `待审阅` - 需要他人审阅
- `阻塞` - 被其他任务阻塞

## 富文本描述

### 编辑描述

1. 打开 TODO 详情面板
2. 在描述字段中输入内容
3. 支持 Markdown 格式

### 支持的 Markdown 格式

```markdown
# 标题
## 子标题

**粗体** *斜体* ~~删除线~~

- 列表项 1
- 列表项 2

[链接](https://example.com)

`代码`

> 引用
```

### 描述显示

- 在列表视图中显示描述的前 100 字符
- 点击展开查看完整描述
- 支持折叠/展开状态记忆

## 任务依赖

### 设置依赖

1. 打开 TODO 详情面板
2. 在"依赖"字段中选择其他 TODO
3. 可以设置多个前置任务

### 依赖功能

- **阻塞提示**: 如果前置任务未完成，当前 TODO 会显示为阻塞状态
- **自动解锁**: 前置任务完成后，当前 TODO 自动变为可用
- **依赖链**: 支持多级依赖关系

### 依赖可视化

在 TODO 视图中：
- 有依赖的 TODO 会显示链状图标
- 悬停显示依赖关系
- 点击图标查看依赖详情

## 递归任务

### 创建递归任务

1. 打开 TODO 详情面板
2. 开启"递归"选项
3. 设置递归规则：
   - **每日**: 每天重复
   - **每周**: 指定星期几重复
   - **每月**: 指定日期重复
   - **自定义**: 自定义间隔

### 递归示例

- **每日站会**: 每个工作日上午 9 点
- **周报告**: 每周五下午 5 点
- **月度总结**: 每月最后一天

### 递归任务行为

- 任务完成后，自动创建下一次的任务
- 保留原任务的所有属性（标题、描述、标签等）
- 可以跳过某次递归
- 可以随时停止递归

## 统计和报告

### 任务统计

在 TODO 视图底部，显示统计信息：

- **总数**: 总 TODO 数量
- **未完成**: 未完成的数量
- **已完成**: 已完成的数量
- **完成率**: 完成百分比

### 每日进度

查看每日完成情况：

- 今天完成了多少任务
- 本周完成趋势
- 本月完成统计

### 导出报告

1. 点击 TODO 视图菜单
2. 选择"导出报告"
3. 选择格式：
   - **Markdown**: 导出为 Markdown 文件
   - **CSV**: 导出为 CSV 文件
   - **JSON**: 导出为 JSON 数据

## 模板系统

### 创建模板

1. 创建一个 TODO，设置好所有属性
2. 右键点击 TODO
3. 选择"保存为模板"
4. 给模板命名

### 使用模板

1. 点击 TODO 视图的"从模板创建"按钮
2. 选择模板
3. 修改需要调整的内容
4. 创建 TODO

### 模板变量

模板支持变量：

- `{{date}}` - 当前日期
- `{{time}}` - 当前时间
- `{{weekday}}` - 星期几
- `{{month}}` - 月份

示例模板标题：
```
{{date}} 每日站会纪要
```
